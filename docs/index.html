MCAI-OS
Easy Flasher

Install or update MCAI-OS from your browser. No separate flashing app required.

Before you start

1Use Chrome or Microsoft EdgeWeb Serial is required. Firefox and Safari are not supported by this installer.
2Connect your Cardputer ADVUse a USB-C cable that supports data, not charging only.
3Click Install / UpdateChoose the serial port named for your Cardputer and keep it connected until flashing finishes.
Checking for a published MCAI-OS firmware…The installer only appears when a firmware release is available.

If the device is not detected, switch it off. Hold the G0 button while connecting USB, then release it. Try another data-capable cable if needed.

Important storage note

The Cardputer ADV microSD card is separate from the ESP32 internal flash. This installer does not format or write to the microSD card. A firmware update can still replace internal flash contents, so back up anything stored internally before installing.

A first-time install may offer an erase option. Erasing internal flash removes firmware and internal-flash data; it does not format the microSD card.
