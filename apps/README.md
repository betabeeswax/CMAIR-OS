# Apps

The canonical app list lives in `catalogue.json`. Every entry has a stable ID, display name, category, target platforms and implementation status.

Statuses:
- `planned`: on the roadmap; not yet implemented.
- `experimental`: available for testing; APIs or behavior may change.
- `working`: implemented and has passing tests on the named target.
- `blocked`: implementation is waiting on hardware, service or compatibility work.

Do not change app display names casually. In particular, the media player is **MLC**.
